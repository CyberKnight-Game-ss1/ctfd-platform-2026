## Overview

`ctfd-theme-neubrutalism` is a custom CTFd theme designed with a **neubrutalist aesthetic** — bold borders, flat colors, and raw typography. It is used as the official UI for the **CyberKnight Weekly Game 2026** platform, maintained by the CyberKnight Core Team at Ton Duc Thang University (TDTU).

The theme is built on top of CTFd's `core-beta` structure using:

- **Bootstrap 5** — responsive grid & components
- **SCSS** — modular, customizable stylesheets (`assets/scss/main.scss`, `assets/scss/_cyberknight.scss`)
- **Vite** — fast bundling with watch mode in dev
- **Vanilla JS** — no Alpine.js dependency (migrated out for stability)
- **ECharts** — scoreboard graphs

This theme lives inside the main platform repo at:
```
ctfd-platform-2026/
└── themes/
    └── ctfd-theme-neubrutalism/   ← you are here
```

## Installation

The theme is already included as part of the [ctfd-platform-2026](https://github.com/CyberKnight-Game-ss1/ctfd-platform-2026) repository. If you want to use it standalone on your own CTFd instance, copy the theme folder into your CTFd `themes/` directory and rename it to `ctfd-theme-neubrutalism`.

Then activate the theme from the CTFd Admin Panel: **Admin → Config → Themes → select `ctfd-theme-neubrutalism`**.

---

## ⚠️ Required CTFd Patch

This theme uses a custom Jinja2 global in `templates/page.html` to display the challenge count on the homepage. You **must** add the following snippet to `CTFd/utils/initialization/__init__.py` inside the `init_template_globals(app)` function:

```python
def get_challenge_count():
    from CTFd.utils.challenges import get_all_challenges
    return len(get_all_challenges())

app.jinja_env.globals.update(get_challenge_count=get_challenge_count)
```

Without this, the homepage challenge counter will raise an `UndefinedError` at runtime.

```

│
├── assets/                      # Source files (edit these)
│   ├── scss/
│   │   ├── main.scss            # Main stylesheet entry point
```

## Development

### Prerequisites

- **Node.js** ≥ 16
- **Yarn** (classic) — [installation guide](https://classic.yarnpkg.com/en/docs/install)

### Setup

```bash
# From the theme root directory
cd themes/ctfd-theme-neubrutalism

# Install dependencies
yarn install
```

### Workflow

| Command | Description |
|---|---|
| `yarn dev` | Watch mode — rebuilds on every save (`vite build --watch --mode=development`) |
| `yarn build` | One-time production build (`vite build`) |
| `yarn format` | Auto-format source files with Prettier |
| `yarn lint` | Check formatting without writing |
| `yarn verify` | Build + verify no uncommitted diff in `static/` |

### Tips

- Run `yarn dev` while CTFd is running locally — Vite recompiles `assets/` → `static/` on every save.
- Hard-refresh the browser (`Ctrl+Shift+R`) to see style changes.
- The `node_modules/` folder is gitignored. Do not commit it or include it in production deployments.
